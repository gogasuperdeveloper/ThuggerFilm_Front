# ThuggerFilm — Онлайн-кінотеатр

## Команда
- Лазарєв Георгій
- Вахно Артем

## Опис
ThuggerFilm — вебзастосунок для онлайн-бронювання квитків у кінотеатр. Відвідувачі можуть переглядати афішу, обирати зручні місця в залі та одразу оплачувати квитки онлайн. Проєкт орієнтований на глядачів, які хочуть уникнути черг і забронювати місце заздалегідь — від вибору фільму до QR-квитка в кілька кліків.

## Ролі
- **Гість**: перегляд афіші та розкладу сеансів, опис фільмів, розташування кінотеатру на карті
- **Користувач**: реєстрація та авторизація, бронювання та оплата квитків, отримання QR-квитка, перегляд історії замовлень
- **Адміністратор**: управління фільмами, сеансами, залами та місцями; перегляд статистики продажів

## Основний функціонал
- Афіша з фільмами (постер, жанр, тривалість, опис, вікова категорія)
- Розклад сеансів із фільтрацією за датою, залом та жанром
- Інтерактивна схема залу для вибору місць
- Бронювання квитків із резервуванням місць у реальному часі
- Оплата через LiqPay (Приватбанк sandbox)
- Генерація QR-коду для кожного квитка
- Особистий кабінет з історією замовлень і статусами
- Відображення адреси кінотеатру через Google Maps API

## Особливість проєкту
Інтеграція з **LiqPay API** (Приватбанк sandbox) для реальної онлайн-оплати квитків та **Google Maps API** для відображення розташування кінотеатру — забезпечує повний шлях від вибору фільму до оплаченого QR-квитка без виходу з платформи.
